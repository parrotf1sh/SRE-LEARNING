| 数据类型                   | 推荐备份方式                     |
| -------------------------- | -------------------------------- |
| Kubernetes 集群状态        | K3s SQLite 一致性备份            |
| MySQL 业务数据             | 数据库逻辑备份或一致性物理备份   |
| Redis 数据                 | 根据缓存可重建性决定是否需要备份 |
| GitOps 配置                | Git 仓库版本历史                 |
| Prometheus / Loki 历史数据 | 根据保留要求与存储后端决定       |
