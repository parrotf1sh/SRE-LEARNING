重要提醒：

1. 确保已创建所需的 Secret：
{{- if .Values.secrets.enabled }}
{{- with .Values.secrets.database.secretName }}
   - 数据库 Secret: {{ . }}（键：DB_HOST、DB_PORT、DB_USER、DB_PASSWORD、DB_NAME）
{{- end }}
{{- with .Values.secrets.redis.secretName }}
   - Redis Secret: {{ . }}（键：REDIS_NODES）
{{- end }}
{{- if or .Values.secrets.database.secretName .Values.secrets.redis.secretName }}

   示例：
   {{- with .Values.secrets.database.secretName }}
   kubectl create secret generic {{ . }} \
     --from-literal=DB_HOST=mysql.default.svc.cluster.local \
     --from-literal=DB_PORT=3306 \
     --from-literal=DB_USER=root \
     --from-literal=DB_PASSWORD='<password>' \
     --from-literal=DB_NAME=task_api \
     -n {{ $.Release.Namespace }}
   {{- end }}
   {{- with .Values.secrets.redis.secretName }}

   kubectl create secret generic {{ . }} \
     --from-literal=REDIS_NODES='redis-node-0:6379,redis-node-1:6380' \
     -n {{ $.Release.Namespace }}
   {{- end }}
{{- end }}
{{- else }}
   Secret 引用已关闭，应用会使用内置默认连接地址，通常只适用于本地开发。
{{- end }}

2. Secret 不由本 Chart 管理，修改 Secret 后需要重启 Pod：
   kubectl rollout restart deployment/{{ include "task-api.fullname" . }} -n {{ .Release.Namespace }}

3. 查看 Pod 状态：
   kubectl get pods -l app.kubernetes.io/name={{ include "task-api.name" . }} -n {{ .Release.Namespace }}

4. 查看应用日志：
   kubectl logs -l app.kubernetes.io/name={{ include "task-api.name" . }} -n {{ .Release.Namespace }} -f

5. 测试健康检查：
   kubectl exec -it deployment/{{ include "task-api.fullname" . }} -n {{ .Release.Namespace }} -- \
     curl -s http://127.0.0.1:{{ .Values.containerPort }}/health
